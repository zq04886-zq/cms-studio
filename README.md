# CMS Studio

移动端可视化页面搭建平台，使用 Vue 2、Express 和 MySQL。管理界面采用 Grok 风格的深灰工作区、窄侧栏和简洁操作布局。

支持页面组件编排、草稿保存、登录预览、发布与下线、图片上传和素材选择、商品导入与展示。两个前端与 API 可由同一个服务提供。

- [运行说明](./运行说明.md)：本机启动、全新安装、数据库初始化与服务器部署。
- [代码分析](./源码分析.md)：目录结构、数据模型、接口及关键实现。
- [验证记录](./verification/测试记录.md)：测试范围与结果。

已有本机环境可执行 `powershell -ExecutionPolicy Bypass -File D:\CMS\启动.ps1`。

仓库：[cms-studio](https://github.com/zq04886-zq/cms-studio)。
